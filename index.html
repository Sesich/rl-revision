Before you walk in

  • Implicationp → q is false only when p is true and q is false. Its negation is p ∧ ¬q.
  • Contrapositive vs converse¬q → ¬p is equivalent to p → q. The converse q → p and inverse ¬p → ¬q are not.
  • Quantifier pairing∀ goes with →, ∃ goes with ∧: ∀x(S(x) → P(x)), ∃x(S(x) ∧ P(x)).
  • Negating quantifiers¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x). Never swap the order of ∀ and ∃.
  • DisprovingAlways give a concrete counterexample: a truth assignment, specific numbers, or a structure D = {…}.
  • Formal proofsNumbered lines, each with its justification (premise, rule, definition). Finish with ∎ or Q.E.D.
  • InductionDefine P(n), do the base case, write "let k be arbitrary", state the IH, mark where you use it, conclude.
  • Structural inductionOne case for every rule of the recursive definition. IH for the parts, show it for the whole.
  • Set equalityShow A ⊆ B and B ⊆ A, each with "let x be arbitrary, assume x ∈ …".
  • ∈ versus ⊆∅ ⊆ A for every A, and ∅ ∈ P(A). P(∅) = {∅}, which has one element.
  • Topological orderingRepeatedly take a vertex with no incoming edges and remove it with its outgoing edges. Only a DAG has one, and it is usually not unique.
  • FunctionsInjective: f(x) = f(y) → x = y. Surjective: take an arbitrary b and construct a with f(a) = b.
  • Countably infiniteGive a bijection from ℕ = {0, 1, 2, …}. ℕ includes 0 in this book.
  • Relation typesEquivalence: reflexive, symmetric, transitive. Partial order: reflexive, antisymmetric, transitive. Total order: partial order where every pair is comparable.
  • Spelling"Prove" is the verb, "proof" is the noun. The book names this the most common mistake on R&L exams.

Proof recipes

Ground rules for every proof

  • Start with "Proof." and name the method ("Proof by contradiction."). End with ∎ or Q.E.D.
  • Write it in list form: one step per line, with its justification next to it.
  • Introduce every variable: "Let x be arbitrary", "for some integer k". Use a new letter for each new witness (k, then m or k′).
  • Justify every step: premise, assumption, definition, named law, IH, algebra, closure of ℤ.
  • Use the definitions: unwind them at the start ("n is even, so n = 2k") and rewind them at the end.
  • Never assume what you are proving, and never "prove" a for-all claim with examples.

Logical equivalence

Show P ≡ Q, or that P is a tautology
  1. Truth table: list all 2ⁿ rows in sorted order (000 … 111).
  2. Add a column for each subformula, working from the inside out.
  3. Compare the final columns. Identical means P ≡ Q; all 1s means a tautology. Write that sentence.
  4. Or a chain of laws: P ≡ … ≡ Q, one law per step, named each time.
  5. Not equivalent: give one row where they differ and compute both values.
p q | ⟨subformulas⟩ | P | Q
0 0 |      …        | … | …
0 1 |      …        | … | …
…
The columns for P and Q are identical in all
2ⁿ rows, so P ≡ Q.

Valid or invalid argument

Premises ∴ conclusion

  3. Valid: numbered lines. Each line is a premise or follows from earlier lines by a named rule, citing the line numbers.

Regular proofs

Direct proof (with generalisation)

∀x(P(x) → Q(x)): "if … then …", "every … is …"
  1. Rewrite the claim as ∀x(P(x) → Q(x)) so you know what to assume and what to reach.
  2. "Let x be arbitrary." Use nothing about x except what you assume.
  3. Assume P(x).
  4. Unwind P with its definition (even: x = 2k for some integer k).
  5. Do the algebra, justifying each line.
  6. Rewind into the definition of Q (write it as 2·(…)) and say why the bracket is an integer.
  7. Conclude: since x was arbitrary, the claim holds for all x.
Proof (direct).
1. Let n ∈ ℤ be arbitrary and
   assume n is even.          [assumption]
2. n = 2k for some integer k  [definition of even]
3. n² = 4k² = 2(2k²)          [algebra]
4. 2k² is an integer          [ℤ closed under ·]
5. n² is even                 [definition of even]
Since n was arbitrary,
∀n ∈ ℤ (n even → n² even). ∎

Contrapositive

p → q when ¬q gives you something concrete and q does not
  1. Say it: "We prove the contrapositive ¬q → ¬p."
  2. Negate both parts carefully: not even = odd, ¬(a ∧ b) ≡ ¬a ∨ ¬b.
  3. Do a direct proof of ¬q → ¬p.
  4. Conclude that p → q holds because it is equivalent to its contrapositive.
Claim: if n² is even, then n is even.
Proof (contrapositive). We prove:
if n is odd, then n² is odd.
1. Let n be arbitrary and assume
   n is odd.                    [assumption]
2. n = 2k + 1, k an integer     [definition of odd]
3. n² = 2(2k² + 2k) + 1         [algebra]
4. n² is odd                    [definition of odd]
So ¬q → ¬p, and p → q ≡ ¬q → ¬p,
so the claim holds. ∎

Proof by contradiction

"… is irrational", "infinitely many", "no … exists"
  1. "Assume, for the sake of contradiction, that …" followed by the exact negation of the claim. For p → q assume p ∧ ¬q; for ∀x P(x) assume some x with ¬P(x).
  2. Derive consequences, with justifications.
  3. Reach a statement r and its negation ¬r, and point to both lines.
  4. "Contradiction. So the assumption is false and the claim holds. ∎"
Proof (by contradiction).
1. Assume, for the sake of contradiction,
   ⟨negation of the claim⟩.    [assumption]
2. ⟨…⟩                         [definition …]
…
i. ⟨r⟩                         [from …]
j. ⟨¬r⟩                        [from …]
Lines i and j contradict each other, so the
assumption is false. Hence ⟨claim⟩. ∎

√3: assume √3 = m/n in lowest terms;
then 3 | m and 3 | n: a common factor.

Division into cases

Claims where parity, remainder or sign matters
  1. Choose cases that together cover everything, and say why (every integer is 3k, 3k + 1 or 3k + 2).
  2. Prove the claim in each case separately. Each case is a small direct proof.
  3. Conclude: the cases cover all possibilities, so the claim holds.
Proof (division into cases).
Let n ∈ ℤ be arbitrary. Every integer has the
form 3k, 3k + 1 or 3k + 2 for some integer k.
Case 1: n = 3k.      … so 3 | ⟨…⟩.
Case 2: n = 3k + 1.  … so 3 | ⟨…⟩.
Case 3: n = 3k + 2.  … so 3 | ⟨…⟩.
The cases cover every integer and n was
arbitrary, so the claim holds. ∎

If and only if

"p iff q", "necessary and sufficient"
  1. Split it: p ↔ q ≡ (p → q) ∧ (q → p).
  2. (⇒) Assume p and show q.
  3. (⇐) Assume q and show p. Each direction may use its own method, e.g. one direct and one contrapositive.
  4. Conclude that both directions hold.
Proof. Since p ↔ q ≡ (p → q) ∧ (q → p),
we prove both directions.
(⇒) Assume p. … Therefore q.
(⇐) Assume q. … Therefore p.
Both directions hold, so p ↔ q. ∎

Example and counterexample

∃x P(x), or disproving ∀x P(x)
  1. ∃x P(x): name one specific element and check P for it by computing.
  2. Disprove ∀x P(x): name one specific element a and show ¬P(a) by computing.
  3. Disprove ∃x P(x): prove ∀x ¬P(x) with a general proof. One example is not enough.
  4. For "prove or disprove", decide first by trying small values.
Claim (false): every prime number is odd.
Counterexample: 2 is prime (its only positive
divisors are 1 and 2), and 2 = 2·1 is even.
So the claim is false.
Induction family

Weak (ordinary) induction

∀n ≥ n₀ P(n) when P(k + 1) follows from P(k)
  1. Define P(n) exactly and the start value n₀.
  2. Base case: compute both sides for n = n₀ separately.
  3. Inductive step: "Let k ≥ n₀ be arbitrary and assume P(k)." Write the IH out in full.
  4. Write the target P(k + 1) in full: replace n by (k + 1) everywhere, with parentheses.
  5. Start from one side of P(k + 1) and rewrite until P(k) appears: split off the last term of a sum, or add and subtract a constant for divisibility.
  6. Apply the IH and label it "(IH)". Finish the algebra to reach the other side.
  7. Conclusion naming the principle of mathematical induction.
Let P(n) be "⟨statement⟩". We prove
∀n ≥ ⟨n₀⟩ P(n) by induction on n.

Base case (n = ⟨n₀⟩):
  LHS = ⟨…⟩, RHS = ⟨…⟩, so P(⟨n₀⟩) holds.

Inductive step:
  Let k ≥ ⟨n₀⟩ be arbitrary and assume
  P(k): ⟨P(k) in full⟩                 (IH)
  We show P(k + 1): ⟨P(k+1) in full⟩
  ⟨LHS of P(k+1)⟩
    = ⟨rewrite so P(k) appears⟩
    = ⟨…⟩                           (by IH)
    = ⟨RHS of P(k+1)⟩
  So P(k + 1) holds.

By the principle of mathematical induction,
P(n) holds for all n ≥ ⟨n₀⟩. ∎

Strong induction

P(k + 1) needs P(k − 1), or some smaller value than k
  1. Define P(n) and n₀.
  2. Base cases: check every value the step cannot handle. If the step looks back two places (fk−1, fk−2), you need two base cases.
  3. Inductive step: "Let k be arbitrary and assume P(j) for all j with n₀ ≤ j ≤ k" (IH).
  4. Show P(k + 1). Say which smaller j you use and why it is between n₀ and k.
  5. Conclusion naming strong induction.
Let P(n) be "⟨…⟩". We prove ∀n ≥ ⟨n₀⟩ P(n)
by strong induction.

Base case(s): P(⟨n₀⟩) [and P(⟨n₀+1⟩)] hold
because ⟨direct check⟩.

Inductive step: Let k ≥ ⟨last base case⟩ be
arbitrary and assume P(j) for all j with
n₀ ≤ j ≤ k.                                (IH)
We show P(k + 1): ⟨k + 1 is built from j₁, j₂⟩.
Since n₀ ≤ j₁, j₂ ≤ k, the IH gives P(j₁) and
P(j₂), so ⟨…⟩ and P(k + 1) holds.

By the principle of strong induction, P(n)
holds for all n ≥ ⟨n₀⟩. ∎

Example: k + 1 not prime ⇒ k + 1 = ab with
2 ≤ a, b ≤ k; the IH applies to a and b.

Structural induction

For every element of a recursively defined set: formulas, trees, strings
  1. Write down the recursive definition: basis rules, constructor rules, exclusivity ("nothing else").
  2. Define P(x). Define any helper function you need (like l(φ) and r(φ)) recursively, with one case per rule.
  3. Base case for every basis rule.
  4. Inductive case for every constructor rule: let the parts be arbitrary, assume P for each part (IH), and show P for the new element.
  5. Conclusion: every rule preserves P and nothing else is in the set.
  6. For trees the rules are ∅, a leaf (x, ∅), and (x, (T₁, …, Tk)) with an IH for every Ti.
Let P(φ) be "⟨property⟩". We prove ∀φ ∈ PROP
P(φ) by structural induction.

Base case (Atoms): ⟨show P(pᵢ)⟩.

Inductive case (Negation): Let x ∈ PROP be
arbitrary and assume P(x).               (IH)
Then ⟨…⟩, so P(¬x).

Inductive case (Binary connective): Let
x, y ∈ PROP be arbitrary and assume P(x)
and P(y).                                (IH)
Then ⟨…⟩, so P((x ∗ y)) for every
∗ ∈ {∧, ∨, →, ↔}.

Every rule preserves P and nothing else is in
PROP, so by structural induction P(φ) holds
for all φ ∈ PROP. ∎

Loop invariant

Prove that a loop computes what it should
  1. Identify the guard (loop condition) and the post-condition you want after the loop.
  2. Choose an invariant I that links the variables to the goal, often "the answer so far". Add bounds such as 0 ≤ i ≤ n if step 6 needs them.
  3. Initialisation: plug the starting values into I.
  4. Maintenance: assume I and the guard for the old values, write the new values from the loop body, and show I for the new values. This is the inductive step.
  5. Termination: some natural-number quantity (like n − i) strictly decreases each iteration, so the guard becomes false.
  6. Correctness: I together with ¬guard gives the post-condition.
i = 0; s = 0
while (i < n) { i = i + 1; s = s + i }
Goal: s = n(n + 1)/2 for n ∈ ℕ.
Invariant I: s = i(i + 1)/2 and 0 ≤ i ≤ n.

1. Initialisation: i = 0, s = 0, and
   0 = 0·1/2, 0 ≤ 0 ≤ n.  ✓
2. Maintenance: assume I and i < n.
   New values i′ = i + 1, s′ = s + i + 1.
   s′ = i(i + 1)/2 + (i + 1)        (by I)
      = (i + 1)(i + 2)/2 = i′(i′ + 1)/2
   and i < n gives i′ ≤ n.  ✓
3. Termination: n − i decreases by 1 each
   iteration and stays ≥ 0, so eventually
   the guard i < n is false.
4. Correctness: I and ¬(i < n) give i = n,
   so s = n(n + 1)/2. ∎
Sets, functions, relations

Set proofs (element chasing)

A ⊆ B, A = B, set identities
  1. A ⊆ B: let x be arbitrary and assume x ∈ A. Translate with the definitions (∩ is ∧, ∪ is ∨, ∖ is "∈ and ∉", complement is ∉) and reach x ∈ B.
  2. A = B: prove A ⊆ B and B ⊆ A, or give one chain x ∈ A ↔ … ↔ x ∈ B with a reason per step.
  3. Not equal, or not a subset: give concrete sets and an element that is in one but not the other.
  4. A Venn diagram is not a proof.
Proof (A ∩ B ⊆ A ∪ B).
1. Let x be arbitrary and assume
   x ∈ A ∩ B.                   [assumption]
2. x ∈ A ∧ x ∈ B                [definition of ∩]
3. x ∈ A                        [simplification]
4. x ∈ A ∨ x ∈ B                [addition]
5. x ∈ A ∪ B                    [definition of ∪]
Since x was arbitrary, A ∩ B ⊆ A ∪ B. ∎

Function proofs and countably infinite

Injective, surjective, bijective, "A is countably infinite"
  1. Is it a function A → B? Every a ∈ A gets exactly one value, and that value lies in B.
  2. Injective: let x, y ∈ A be arbitrary and assume f(x) = f(y); derive x = y.
  3. Surjective: let b ∈ B be arbitrary; solve f(a) = b for a; check a ∈ A; verify f(a) = b.
  4. Bijective: prove both.
  5. Countably infinite: give f: ℕ → A, show it is a bijection, and say "there is a bijection from ℕ to A, so A is countably infinite."
  6. If A is several infinite "streams", interleave them: n even/odd for two streams; n = 3k, 3k + 1, 3k + 2 for three.
A = positive integers ending in 3 or 7.
f: ℕ → A,
f(n) = 10·(n/2) + 3        if n is even
       10·((n − 1)/2) + 7  if n is odd
This lists A as 3, 7, 13, 17, 23, 27, …

Injective: even n give values ending in 3,
odd n give values ending in 7, and within
each case f is strictly increasing.
Surjective: a = 10m + 3 has n = 2m;
a = 10m + 7 has n = 2m + 1.
So f is a bijection from ℕ to A, hence A is
countably infinite.

With negatives like −7 included, use three
streams: 10k + 3, 10k + 7, −(10k + 7) for
n = 3k, 3k + 1, 3k + 2.

Relation proofs

"Show R is an equivalence relation / a partial order"
  1. Write each required property as its formula.
  2. Reflexive: let a be arbitrary; show a R a.
  3. Symmetric: let a, b be arbitrary and assume a R b; show b R a.
  4. Antisymmetric: let a, b be arbitrary and assume a R b and b R a; show a = b.
  5. Transitive: let a, b, c be arbitrary and assume a R b and b R c; show a R c.
  6. Conclude: reflexive + symmetric + transitive is an equivalence relation; reflexive + antisymmetric + transitive is a partial order. To show a property fails, give one concrete counterexample.
x ~ y iff x − y ∈ ℤ, on ℝ.
Reflexive: let x ∈ ℝ. x − x = 0 ∈ ℤ,
  so x ~ x.
Symmetric: let x, y ∈ ℝ with x ~ y, so
  x − y = k ∈ ℤ. Then y − x = −k ∈ ℤ,
  so y ~ x.
Transitive: let x, y, z ∈ ℝ with
  x − y = k ∈ ℤ and y − z = m ∈ ℤ.
  Then x − z = k + m ∈ ℤ, so x ~ z.
So ~ is an equivalence relation. ∎

With n variables a truth table has 2n rows. Write rows in sorted order (000, 001, …, 111). From a false premise anything follows, so p → q is true whenever p is false (principle of explosion).

Classifying propositions

A tautology is true in every row, a contradiction is false in every row, a contingency is neither. P is a tautology iff ¬P is a contradiction. P and Q are logically equivalent (P ≡ Q) iff P ↔ Q is a tautology. A set of operators is functionally complete if every formula can be rewritten with only those operators: {¬, ∨}, {¬, ∧} and {↓} (NOR, p ↓ q ≡ ¬(p ∨ q), so ¬p ≡ p ↓ p) all are.

Normal forms (examined)

A simple term is a variable or its negation. DNF is a disjunction of conjunctions of simple terms; CNF is a conjunction of disjunctions of simple terms. In each conjunction (or disjunction) a variable appears at most once.

Recipe from a truth table
  1. DNF: take every row with output 1. For that row, AND the variables, writing x if it is 1 and ¬x if it is 0. OR all these conjunctions together.
  2. CNF: take every row with output 0. For that row, OR the variables, writing x if it is 0 and ¬x if it is 1 (the clause is false exactly on that row). AND all these clauses together.
  3. Simplify with the laws, or with a K-map (the book allows both for DNF).

Predicate logic

A predicate becomes a proposition once you fill its slots with entities from the domain of discourse. P(x) on its own is an open statement, not a proposition: x is free. In ∀x P(x) or ∃x P(x) the variable is bound. ∃ means "there is at least one".

Strong induction

Inductive case: "Let k be arbitrary and assume P(n₀), P(n₀ + 1), …, P(k). Show P(k + 1)." Use it when P(k + 1) depends on smaller cases than just k: writing k + 1 = ab with 2 ≤ a, b ≤ k (every n > 1 is a product of primes), trees split into subtrees of any smaller size, or a recursion like fn = fn−1 + fn−2.

If the step reaches back two places (k − 1 and k − 2), you need two base cases. The Fibonacci bound fn > 1.5n−1 for n ≥ 6 checks n = 6 and n = 7 before the step for k > 7. Also: "assume P(k) for all k" assumes what you are proving. Fix k first.

Trees

  • Root: node with no parent. Leaf: node with no children.

Handy facts

Functions

A function f: A → B is a subset of A × B that contains, for every a ∈ A, exactly one pair (a, b). Then f(a) = b. A is the domain, B the range, and the image is {f(a) | a ∈ A} ⊆ B.

Trap

In this book "range" means the whole set B (what other books call the codomain). Calculus uses "range" for the image.

Example with X = {a, b}, Y = {1, 2, 3}: {(a, 2), (b, 1)} is a function X → Y. {(1, a), (2, b)} is not a function Y → X (no value for 3), and {(a, 1), (a, 2), (b, 3)} is not a function X → Y (two values for a).

Composition

For f: A → B and g: B → C, (g ∘ f)(a) = g(f(a)): apply f first. Composition is associative but not commutative: with s(n) = n² and r(n) = 3n + 1, (r ∘ s)(n) = 3n² + 1 while (s ∘ r)(n) = (3n + 1)².

  • g ∘ f injective ⇒ f injective
  • g ∘ f surjective ⇒ g surjective

Functions as objects

BA is the set of all functions A → B, so f: A → B means f ∈ BA, and |BA| = |B||A|.

On recursive structures, define functions with one case per rule, e.g. the tree height h above. A weight function w: E → ℕ turns a graph into a weighted graph (shortest paths).

Example: X = {a, b, c, d, e}, Y = {c, d, e, f}. |X × Y| = 20, |X ∪ Y| = 5 + 4 − 3 = 6, |XY| = 5⁴ = 625.

Countable infinity

Countably infinite: there is a bijection ℕ → A (an infinite list f(0), f(1), f(2), … that hits every element once). Countable: finite or countably infinite. Uncountable: infinite but not countably infinite.

  • The union of two countable sets is countable.
  • ℝ is uncountable (Cantor's diagonalisation). If X is uncountable and K ⊆ X is countable, X ∖ K is uncountable, so the irrationals are uncountable.
  • No set X has a bijection with P(X), so there is no largest cardinality.
Scope

You must be able to prove a set is countably infinite by giving a bijection from ℕ and proving it injective and surjective. You will not be asked to prove a set is uncountable.

Relations

A binary relation on A is a subset R ⊆ A × A; a R b means (a, b) ∈ R. A function is a special kind of relation.

Orders

Partial order: reflexive, antisymmetric, transitive. Examples: ≤ on ℕ, ⊆ on P(X), "divides" on ℤ⁺.

Total order: a partial order where a R b or b R a for every pair. ≤ is total; ⊆ and "divides" are not (2 and 3).

Equivalence

Equivalence relation: reflexive, symmetric, transitive. Equivalence class [a]R = {b ∈ A | b R a}.

The classes form a partition of A (non-empty, pairwise disjoint, union is A), and every partition gives an equivalence relation (Theorem 4.12).

Trap

Symmetric and antisymmetric are not opposites: = is both, and a relation can be neither. To show a property fails, one counterexample pair is enough; to show it holds, argue for arbitrary elements.

Standard equivalences

  • n ~ m iff 3 | (n − m) on ℤ: classes [0], [1], [2]
  • x ~ y iff x − y ∈ ℤ on ℝ: each class has exactly one element in [0, 1)
  • x ~ y iff f(x) = f(y), for any function f
  • X ~ Y iff there is a bijection X → Y (same cardinality)

Transitive closure

a R* b iff there is a chain a = x₀ R x₁ R … R xn = b with n > 0 ("in one or more steps"). If x R y means y = x + 1 on ℕ, then R* is <. If R is "child of", R* is "descendant of".

PropositionalIs (p → q) → r equivalent to p → (q → r)?

No. With p = q = r = 0: (0 → 0) → 0 = 1 → 0 = 0, but 0 → (anything) = 1.

PropositionalSimplify ¬(p → q) ∨ q.

(p ∧ ¬q) ∨ q (negated implication) ≡ (p ∨ q) ∧ (¬q ∨ q) (distributive) ≡ (p ∨ q) ∧ T (excluded middle) ≡ p ∨ q (identity).

PropositionalGive the DNF and the CNF of p ↔ q.

True on rows 00 and 11: DNF (¬p ∧ ¬q) ∨ (p ∧ q). False on rows 01 and 10: CNF (p ∨ ¬q) ∧ (¬p ∨ q).

PredicateTranslate "Only students get a discount" with S(x) and D(x).

∀x(D(x) → S(x)). "Only S" puts S on the right of the arrow.

PredicateNegate ∀x∃y(P(x,y) → Q(y)) with ¬ only on predicates.

∃x∀y(P(x,y) ∧ ¬Q(y)): flip both quantifiers, then ¬(a → b) ≡ a ∧ ¬b.

PredicateTranslate "No student failed every exam" with S(x), E(y), F(x,y).

¬∃x(S(x) ∧ ∀y(E(y) → F(x,y))), equivalently ∀x(S(x) → ∃y(E(y) ∧ ¬F(x,y))).

DeductionValid? p → q, ¬r → ¬q, ¬r ∴ ¬p

Valid. 1. ¬r → ¬q (premise) 2. ¬r (premise) 3. ¬q (1, 2 modus ponens) 4. p → q (premise) 5. ¬p (4, 3 modus tollens). ∎

DeductionValid? p ∨ q, p → r ∴ r

Invalid. Counterexample p = 0, q = 1, r = 0: both premises are true, the conclusion is false.

DeductionShow ∃x P(x), ∃x Q(x) ∴ ∃x(P(x) ∧ Q(x)) is invalid.

Structure D = {a, b}, P = {a}, Q = {b}. Both premises hold, but no element is in both P and Q.

ProofsProve: for every integer n, if 3n + 2 is odd then n is odd.

Contrapositive: assume n is even, so n = 2k. Then 3n + 2 = 6k + 2 = 2(3k + 1), which is even. Since n was arbitrary, the claim holds. ∎

ProofsProving p → q by contradiction: what exactly do you assume?

p ∧ ¬q: the hypothesis holds and the conclusion fails. Then derive some r ∧ ¬r.

InductionWhat is wrong with "Inductive step: assume P(k) holds for all k"?

It assumes the whole claim. Write "Let k ≥ n₀ be arbitrary and assume P(k)", then prove P(k + 1) for that k.

InductionProve Σi=1n (2i − 1) = n² for n ≥ 1.

Base: n = 1 gives 1 = 1². Step: let k ≥ 1 be arbitrary and assume the sum up to k is k². Then Σi=1k+1(2i − 1) = k² + (2k + 1) (IH) = (k + 1)². By induction the formula holds for all n ≥ 1. ∎

InductionWhen do you need strong induction or more than one base case?

When P(k + 1) relies on cases other than P(k): k + 1 = ab with smaller a, b, subtrees of arbitrary smaller size, or recurrences that look back two steps (then check two base cases).

SetsA = {a, {b}, {a, b}} with a ≠ b. True or false: b ∈ A, {a, b} ⊆ A, {a, {b}} ⊆ A?

b ∈ A is false. {a, b} ⊆ A is false (b ∉ A), although {a, b} ∈ A is true. {a, {b}} ⊆ A is true because a ∈ A and {b} ∈ A.

SetsHow many elements does P(P(∅)) have?

Two: P(∅) = {∅}, so P(P(∅)) = {∅, {∅}}.

SetsProve A ∩ B ⊆ A ∪ B.

Let x be arbitrary and assume x ∈ A ∩ B. Then x ∈ A ∧ x ∈ B (definition of ∩), so x ∈ A (simplification), so x ∈ A ∨ x ∈ B (addition), so x ∈ A ∪ B (definition of ∪). Since x was arbitrary, A ∩ B ⊆ A ∪ B. ∎

Functionsf: ℤ → ℤ, f(n) = 2n + 3. Injective? Surjective?

Injective: 2x + 3 = 2y + 3 gives x = y. Not surjective: 2n + 3 is always odd, so 4 has no preimage.

Functionsf(x) = x + 1 and g(x) = x² on ℤ. Give g ∘ f and f ∘ g.

(g ∘ f)(x) = (x + 1)², (f ∘ g)(x) = x² + 1. They differ (x = 1 gives 4 and 2).

CardinalityShow that the odd natural numbers form a countably infinite set.

f: ℕ → O, f(n) = 2n + 1. Injective: 2x + 1 = 2y + 1 gives x = y. Surjective: an odd m = 2k + 1 has preimage k = (m − 1)/2 ∈ ℕ. So f is a bijection. ∎

Cardinality|A| = 3 and |B| = 2. How many functions A → B, and how many B → A?

|BA| = 2³ = 8 and |AB| = 3² = 9.

RelationsOn {1, 2, 3}: R = {(1,1),(2,2),(3,3),(1,2),(2,1)}. Which properties?

Reflexive, symmetric and transitive, not antisymmetric ((1,2) and (2,1) with 1 ≠ 2). It is an equivalence relation with classes {1, 2} and {3}.

RelationsIs the empty relation on {1, 2} reflexive, symmetric, transitive?

Not reflexive (no (1,1)). Symmetric, antisymmetric and transitive hold vacuously.

Relationsn ~ m iff 3 | (n − m) on ℤ. What are the equivalence classes?

[0] = {…, −3, 0, 3, …}, [1] = {…, −2, 1, 4, …}, [2] = {…, −1, 2, 5, …}. Three classes that partition ℤ.
